## Hosting this portfolio with GitHub Pages

1. Commit and push the new files (index.html and assets/) to the `main` branch:

   git add index.html assets/css/styles.css
   git commit -m "Add minimal portfolio index and styles"
   git push origin main

2. In your repository on GitHub, go to Settings → Pages and set the source to the `main` branch and the root (/) folder. GitHub will provide a URL like `https://<username>.github.io/<repo>/` or `https://<username>.github.io/` (for user/organization sites).

3. Wait a minute for the site to publish, then visit the provided URL.

That's it — your minimal portfolio should be live. Expand `index.html` with more sections, links, and images as needed.
